# SEO Checklist

- Run: curl https://buildmycvnow.com | grep '<h1'
- Confirm view-source shows homepage content with JavaScript disabled.
- Open https://buildmycvnow.com/sitemap.xml and validate XML.
- Open https://buildmycvnow.com/robots.txt and confirm /builder is disallowed.
- Register Google Search Console domain property via DNS TXT.
- Submit sitemap: https://buildmycvnow.com/sitemap.xml
- Request indexing for /, /templates, /cv-examples, and top /cv/ pages.
- Repeat in Bing Webmaster Tools.
