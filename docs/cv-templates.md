# CV Templates and Career Journal

Run `npm run dev`, then open `/templates` for the gallery or `/blog/` for the guide cards. Run `node --test tests/cv-templates.test.mjs tests/profile-photo.test.mjs` and `node scripts/check-templates-and-guides.mjs` for the focused checks. Set `BROWSER_PATH` for a Chromium browser other than the default Windows Edge installation.

- `src/data/cvTemplates.js` is the versioned catalog and style validator; `cvTemplateSamples.js` contains the separate fictional content. The gallery shows WebP thumbnails generated by `scripts/generate-cv-template-thumbnails.mjs`; preview and PDF share `templateDocument.js`. Word uses its own mapper and may reflow pages.
- Template settings are saved separately from the CV text inside `cv_data.templateStyle`. The draft initializer validates inputs on the server; the builder stores the new draft in the browser. Existing CV copies require the signed-in owner's account. The existing cloud save and verified-download flows remain in place.
- The catalog has public list and sample routes. There is no new server-side guest draft store, standalone style/export API, or admin UI; catalog changes still go through the code repository. The draft initializer uses the platform's 20 requests per 180 seconds per IP rule. No database migration is required.
- The fonts in `public/assets/cv-fonts` are self-hosted Fontsource distributions with their accompanying licenses. Arabic uses the matching Noto Arabic family and right-to-left layout.
- The journal uses the existing article catalog and GSAP. The card controls do not depend on hover, and reduced-motion users get the same content without 3D motion.
